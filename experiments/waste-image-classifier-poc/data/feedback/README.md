# Feedback Data

This directory holds the feedback contract template for Phase 0.7.

Local feedback data must not be committed:

- `data/feedback/feedback_manifest.csv`
- `data/feedback/images/`
- `data/feedback/candidates/`

Use `feedback_manifest.template.csv` as the schema example, then keep real reviewed rows and local images in the ignored paths above. Candidate outputs built from feedback are generated artifacts and should remain local.
